## شروع کار

1. کل این پوشه را یک‌جا نگه دار. نوت‌بوک و پوشه `fonts` باید کنار هم باشند.
2. در ترمینال: `pip install pytse-client`
3. سلول فونت را اجرا کن، بعد سلول `load`.
4. هر سؤال را بخوان، بخش `# To Do` را کامل کن، بعد سلول را اجرا کن.

قیمت سهم به ریال است. `load("فولاد")` یک دیکشنری می‌دهد. برای نماد دیگر همان تابع را با اسم آن نماد صدا بزن. در لیست `history` کلید `adj` قیمت پایانی است و کلید `last` آخرین معامله همان روز.
