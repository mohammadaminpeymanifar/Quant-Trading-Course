## شروع کار

1. کل این پوشه را یک‌جا نگه دار. نوت‌بوک و پوشه `fonts` باید کنار هم باشند.
2. اگر لازم است، در ترمینال بنویس: `pip install requests`
3. فایل نوت‌بوک را با Jupyter یا Cursor باز کن.
4. سلول فونت را اجرا کن، بعد سلول ابزار API را اجرا کن.
5. هر سؤال را بخوان، بخش `# To Do` را کامل کن، بعد سلول را اجرا کن.

اینترنت لازم است. قیمت‌ها از سایت tgju، نوبیتکس، والکس، بیت‌پین، تترلند، اکسیر و تبدیل می‌آیند. رقم قالب خروجی نمونه یک لحظه بازار است. شکل خط‌ها باید مثل قالب باشد و خود عدد، قیمت همان لحظه اجرای توست.

## واحدها

- tgju برای دلار و سکه: ریال. تقسیم صحیح بر ۱۰ = تومان. اونس و بیت‌کوین جهانی: دلار.
- نوبیتکس در بازار ریالی: ریال. بازار `btc-usdt`: دلار.
- والکس، بیت‌پین، تترلند، اکسیر و تبدیل: تومان.
