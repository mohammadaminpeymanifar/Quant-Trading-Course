ابزارهای آماده پروژه

همه داده‌ها واقعی هستند و از API عمومی سایت‌ها و صرافی‌ها گرفته می‌شوند. هیچ کتابخانه واسطی لازم نیست، فقط requests.

pip install requests

توضیح کامل هر API، با نمونه واقعی جواب و معنی همه کلیدها، در فایل راهنمای_API.html است. قبل از شروع پروژه آن را بخوان و «سلول تست» آخرش را اجرا کن.

این دو ابزار را در اولین سلول نوت‌بوک کپی و اجرا کن.

ابزار ۱: get_json(url)

همان ابزار هفته ۴، بدون تغییر:

import requests

def get_json(url):
    response = requests.get(
        url,
        headers={"User-Agent": "Mozilla/5.0", "Accept": "application/json"},
        timeout=30,
    )
    response.raise_for_status()
    return response.json()

ابزار ۲: save_report(lines, filename)

لیستی از رشته‌ها را خط‌به‌خط در فایل می‌نویسد.

def save_report(lines, filename):
    with open(filename, "w", encoding="utf-8") as f:
        for line in lines:
            f.write(line + "\n")
    print("گزارش ذخیره شد:", filename)

روش استفاده: هر خطی که می‌خواهی در گزارش باشد را به یک لیست append کن و آخر کار save_report(report, "report.txt") بزن.

بقیه پروژه همان چیزهایی است که در CW، HW و میان‌ترم نوشتی: لیست، دیکشنری، set، حلقه، if، الگوی best = None، .items()، replace و int. فقط این چهار تا تازه‌اند. هر کدام یک قالب آماده دارد. کپی کن و فقط اسم‌ها را عوض کن.

تازه ۱: try / except، یعنی «اگر خطا داد، نخواب»

وقتی یک سایت جواب نمی‌دهد، get_json خطا می‌دهد و کل برنامه می‌ایستد. try می‌گوید «امتحان کن». except می‌گوید «اگر خطا شد، به‌جایش این کار را بکن».

prices = {}

try:
    q = get_json("https://service.tetherland.com/api/v4/currencies")
    prices["Tetherland"] = q["price"]
except Exception:
    print("تترلند جواب نداد، رد شدم")

# برنامه این‌جا ادامه می‌دهد، چه تترلند جواب داده باشد چه نه
print(prices)

هر صرافی را در یک try جدا بگذار. اگر همه را در یک try بگذاری، خطای اولی بقیه را هم می‌پراند.

تازه ۲: مرتب کردن لیستی از نتیجه‌ها

sorted را روی set و رشته استفاده کردی. روی لیست دیکشنری کار نمی‌کند. ولی روی لیست تاپل کار می‌کند و اول بر اساس عضو اول مرتب می‌کند:

pairs = [(2, "فولاد"), (3, "فملی"), (1, "وبملت")]
print(sorted(pairs))        # [(1, 'وبملت'), (2, 'فولاد'), (3, 'فملی')]

برای از زیاد به کم، عدد را منفی کن:

pairs = []
for r in results:                       # results لیست دیکشنری‌های توست
    pairs.append((-r["score"], r["symbol"]))
for neg_score, symbol in sorted(pairs):
    print(symbol, -neg_score)

راه دوم (که بلدی): با الگوی best = None بزرگ‌ترین را پیدا کن، چاپش کن، از لیست حذفش کن و تکرار کن.

تازه ۳: جدول مرتب در گزارش

f"{x:.2f}" را در میان‌ترم دیدی. دو گزینه دیگر از همان خانواده:

نوشتن یعنی مثال خروجی
f"{x:,}" ویرگول هزارگان 2,595,100,000
f"{x:,.2f}" ویرگول + دو رقم اعشار 4,171.37
f"{name:<10}" متن ۱۰ خانه، چپ‌چین فولاد
f"{x:>12,}" عدد ۱۲ خانه، راست‌چین با ویرگول 2,595,100

اگر جدول‌بندی اذیتت کرد، ساده بنویس و ستون‌ها را با | جدا کن. نمره کم نمی‌شود:

report.append(f"{symbol} | {close:,} | {change:.2f}% | {signal}")

حقه ۱: انحراف معیار بدون numpy

variance = 0
for r in returns:
    variance += (r - mean) ** 2
variance = variance / (len(returns) - 1)
std = variance ** 0.5

انحراف معیار یعنی «عددها به‌طور معمول چقدر از میانگین دورند». مثال: بازده‌های [1, -1, 3, 1] درصد. میانگین ۱ است. فاصله‌ها ۰، ۲−، ۲، ۰ هستند. مجذورها ۰، ۴، ۴، ۰ و جمعشان ۸. تقسیم بر ۳ می‌شود ۲.۶۷ و ریشه‌اش ۱.۶۳. یعنی بازده معمولاً حدود ۱.۶ درصد بالا و پایین میانگین است.

اگر گیر کردی

خطا معمولاً یعنی چه کنم
KeyError: 'xxx' کلیدی که نوشتی در دیکشنری نیست print(list(data.keys())) و اسم درست را ببین. حرف بزرگ و کوچک، «ی» عربی و فارسی
TypeError: ... 'str' and 'int' با متن حساب کردی replace(",", "") و بعد int() یا float()

IndexError: list index out of range لیست کوتاه‌تر از چیزی است که فکر می‌کردی print(len(...))
ZeroDivisionError تقسیم بر صفر (مثلاً تعداد خریدار صفر) قبلش با if چک کن
HTTPError: 403 یا 429 سایت تو را بست یا زیاد درخواست زدی فیلترشکن را خاموش کن، چند دقیقه صبر کن، time.sleep(1) بگذار
