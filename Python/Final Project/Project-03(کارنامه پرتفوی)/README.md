## 🎯 چرا این پروژه؟

«سود زیاد به تنهایی معنی ندارد. سبدی که ۵۰٪ سود داده ولی وسط راه نصف شده، با سبدی که آرام ۴۰٪ بالا رفته یکی نیست.»

پرسش ساده‌ای که این پروژه به آن جواب می‌دهد:

> **اگر به‌جای این چند سهم، طلا یا دلار یا بیت‌کوین می‌خریدم، وضعم بهتر بود؟**

پاسخ با یک عدد یا یک بازده ساده داده نمی‌شود. باید همزمان نگاه کرد به:

- **بازده**: پول چقدر بزرگ شد؟
- **ریسک**: در این راه چقدر بالا و پایین رفت؟
- **سود به ازای هر واحد ریسک**: شارپ و سورتینو
- **بدترین لحظه**: بیشترین افت از سقف (Max Drawdown)
- **هزینه واقعی**: کارمزد و مالیات چه بلایی سر سود آورد؟

این پروژه یک **کارنامه شش‌ماهه** می‌سازد که همه این‌ها را کنار هم می‌گذارد و رتبه هر دارایی را نشان می‌دهد.
