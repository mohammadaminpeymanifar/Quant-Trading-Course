## شروع کار

1. کل این پوشه را یک‌جا نگه دار (نوت‌بوک و پوشه `fonts` باید کنار هم باشند).
2. فایل نوت‌بوک را با Jupyter یا Cursor باز کن.
3. **اولین سلول کد** را اجرا کن تا فونت وزیر و رنگ‌ها اعمال شود.
4. هر سؤال را بخوان، بخش `# To Do` را کامل کن، بعد سلول را اجرا کن.

نصب فونت روی ویندوز اختیاری است. اگر خواستی، برو به `fonts` و فایل‌های `ttf` را Install کن. راهنما داخل `fonts/راهنمای_نصب_فونت.md` است.
